# 🌿 Cutters Landscaping — Premium Pitch Site

A premium, editorial-grade sales demo website built to pitch a full brand and web redesign to **Cutters Landscaping** (Austin & Dallas, TX).

## Tech Stack
- **React 19** + TypeScript
- **Vite 6**
- **Tailwind CSS v4**
- **Framer Motion** (animations)
- **Lucide React** (icons)

## Run Locally
```bash
npm install
npm run dev
```
App runs at `http://localhost:3000`.
